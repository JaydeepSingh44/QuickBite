QuickBite is a full‑stack, real‑time food delivery application built with the MERN stack.
It replicates the modern food delivery experience seen in apps like Swiggy or Zomato, but with new enhancements that make it stand out.

🔗 Live Demo: (https://quickbite-8e31.onrender.com/)

🛠️ Tech Stack
Frontend: React + Vite

Backend: Node.js + Express

Database: MongoDB

Authentication: JWT & Google Auth

Real‑Time Updates: WebSockets (Socket.IO)

Deployment: Render (backend + Frontend) Both


## Features
🛒 Browse Restaurants & Menus → Interactive UI for food discovery.

📦 Cart & Checkout Flow → Add items, manage cart, and place orders.

🔐 Secure Authentication → JWT‑based login & signup.

⚡ Real‑Time Order Tracking → Live updates using WebSockets.

📜 Order History & Persistence → Track past orders with MongoDB.

📱 Responsive UI → Works seamlessly across devices.


## What’s New in QuickBite (Compared to Others)
Real‑Time Order Status → Customers see live updates (Accepted → Preparing → Out for Delivery → Delivered).

Restaurant Dashboard → Separate interface for restaurants to manage menus and orders.

Delivery Partner Flow → Track delivery agents in real time.

Recruiter‑Ready Codebase → Modular, secure, and production‑friendly with clear documentation.

Scalable Architecture → Designed for future features like payment integration, push notifications, and AI‑powered recommendations.
